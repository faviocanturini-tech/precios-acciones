PROCEDIMIENTO OBLIGATORIO - PROTECCION DE DATOS
=============================================================================
ANTES de cualquier operacion que modifique archivos en data/:

1. Ejecutar: crear_backup_datos("motivo_descriptivo")
2. Si algo sale mal: restaurar_backup("data/backups/YYYYMMDD_HHMMSS_motivo")

Operaciones que REQUIEREN backup previo:
- git checkout de archivos en data/
- git reset que afecte data/
- Copiar archivos sobre existentes en data/
- Sincronizacion con GitHub
